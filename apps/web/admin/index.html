Không thể tự khóa hoặc tự gỡ quyền ADMIN của tài khoản đang đăng nhập. JWT của tài khoản bị khóa mất hiệu lực ở yêu cầu API tiếp theo. Nhật ký không lưu request body, mật khẩu, token hoặc IP.
